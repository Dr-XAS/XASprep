# EasyXASCalc web design

The maintained implementation guide is [UI_DESIGN_GUIDE.md](UI_DESIGN_GUIDE.md).

The app uses the Dr.XAS compact scientific-workbench conventions: self-hosted
Figtree, semantic light/dark tokens, Magma action accents, a responsive controls
rail, and an energy-domain absorption/transmission viewer. Presentation controls
preserve calculation data and user view state. Local asset provenance and licenses
are in `frontend/src/design-system/`.

Use the maintained guide and actual frontend source for component, typography,
scientific-state and verification details; do not copy the former global light-only
CSS or animated plot-card design.
